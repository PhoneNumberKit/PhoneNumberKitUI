# Changelog

## 1.0.0

Initial release. The UIKit components (`PhoneNumberTextField`, country-code picker, and
`CountryCodePickerOptions`) extracted from PhoneNumberKit 4.x into their own package as part of
the 5.0 reboot.

- Depends on [PhoneNumberKit](https://github.com/PhoneNumberKit/PhoneNumberKit) `5.0.0+`.
- iOS 13+. UIKit only.
- API is unchanged from PhoneNumberKit 4.x aside from the new `import PhoneNumberKitUI`.
